# Super Admin Guide

The Super Admin role has the highest level of access within the system, overseeing all schools, configurations, and global settings.

## System Configuration

Manage global settings that apply across all branches or instances of the ERP.

### Academic Years
Create and manage academic sessions, setting start and end dates.

### Global Settings
Configure system-wide preferences, localization (timezone, currency), and feature toggles.

## School Management

Oversee individual school branches within the system.

### Add New School
Register a new school branch, specifying its details, logo, and contact information.

### Manage Schools
View, edit, or deactivate existing school branches.

## User & Role Management

Control who has access to the system and what they can do.

### Manage Roles
Define custom roles with specific permissions for different staff types.

### Manage Admins
Create and manage administrator accounts for each school branch.
